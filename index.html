Apa itu Internet of Things?

Arsitektur & Alur Kerja

Wi-Fi vs Internet

Wi-Fi
Teknologi koneksi jaringan nirkabel.
Internet
Jaringan global yang menghubungkan berbagai jaringan.

Wi-Fi adalah salah satu cara ESP32 terhubung ke jaringan; Internet memungkinkan komunikasi dengan sistem di luar jaringan lokal.

IP Address

Alamat perangkat di jaringan. Router memberi IP ke setiap perangkat:

Router
 ├── Laptop → 192.168.1.5
 ├── HP     → 192.168.1.7
 └── ESP32  → 192.168.1.10

Datastream / Virtual Pin


Platform IoT (misalnya Blynk) memakai saluran data virtual:


V0
Kontrol Pintu
V1
Status Pintu
V2
Status Wi-Fi


V0 = 1 → perintah membuka pintu. V0 = 0 → perintah mengunci pintu.


Komunikasi dua arah: ESP32 → aplikasi (status) dan aplikasi → ESP32 (perintah).

Troubleshooting Koneksi IoT


Kasus 1 – ESP32 tidak terhubung Wi-Fi
  • SSID & password benar?
  • Wi-Fi/hotspot aktif?
  • Jarak ESP32 ke router
  • Koneksi router


Kasus 2 – ESP32 terhubung, aplikasi tidak
  • Koneksi Internet
  • Konfigurasi platform
  • Token/device credentials
  • Datastream
  • Kode MicroPython


Kasus 3 – Tombol ditekan, relay tidak bergerak
Telusuri berurutan:
Aplikasi → Datastream → ESP32 → Program → GPIO → Relay


Kasus 4 – Relay bekerja terbalik
Periksa logika relay Active HIGH atau Active LOW. Coba di simulator!


Kasus 5 – Relay bekerja, solenoid tidak bergerak
  • Power supply & tegangan solenoid
  • Kabel relay & solenoid
  • Common / NO / NC relay
  • Kondisi solenoid
